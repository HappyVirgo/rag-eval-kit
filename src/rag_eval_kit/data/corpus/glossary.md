# Glossary

> Synthetic documentation for Larkspur, a fictional project-management SaaS. Not a real product.

## Account terms

A workspace is the top-level container for projects, members and billing. A seat is a paid license for one member of a workspace. A guest is an external collaborator with restricted access. The billing contact is the person who receives invoices by email.

## Developer terms

An API key is a secret that identifies a workspace when calling the API. A webhook endpoint is a URL on your server that receives event notifications. An event is a record that something changed, such as a task being created. A cursor is an opaque pointer to a position in a list of results.
