# Legacy Plans

> Synthetic documentation for Larkspur, a fictional project-management SaaS. Not a real product.

## Retired plans

The Starter plan and the Pro plan are retired and no longer sold. Workspaces that subscribed before April 2024 can stay on them for as long as their subscription stays active.

## Legacy pricing and limits

Starter cost $8 per user per month and allowed 120 API requests per minute. Pro cost $20 per user per month and allowed 600 API requests per minute. Legacy plans do not include SAML single sign-on, audit logs, or ACH payments.

## Moving to a current plan

Legacy workspaces can switch to a current plan at any time from Settings > Billing. Switching is one-way: after moving to a current plan, you cannot return to a legacy plan.
