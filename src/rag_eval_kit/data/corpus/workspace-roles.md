# Workspace Roles

> Synthetic documentation for Larkspur, a fictional project-management SaaS. Not a real product.

## Roles

A workspace has four roles: Owner, Admin, Member, and Guest. Each workspace has exactly one Owner. Ownership can be transferred to an existing Admin from Settings > General.

## Permissions

Owners control billing, can delete the workspace, and can start full exports. Admins manage members, integrations, and API keys, but cannot change billing. Members create and edit projects and tasks. Guests can only view and comment on projects they were invited to.

## Custom roles

Custom roles with fine-grained permissions are available on the Enterprise plan only.
