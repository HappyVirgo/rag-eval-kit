# Mobile App

> Synthetic documentation for Larkspur, a fictional project-management SaaS. Not a real product.

## Platforms

The Larkspur mobile app is available for iOS 16 or newer and Android 10 or newer. It supports viewing and editing tasks, commenting, and uploading photos as attachments.

## Offline mode

Tasks you opened recently are cached on the device so you can read them without a connection. Edits made offline are queued and synced when the device reconnects; if someone else changed the same field in the meantime, the most recent edit wins.

## Signing in

The mobile app supports password, SSO and passkey sign-in. Biometric unlock can be turned on in the app settings so you do not need to type your password each time.
