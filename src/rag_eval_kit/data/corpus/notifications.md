# Notifications

> Synthetic documentation for Larkspur, a fictional project-management SaaS. Not a real product.

## Channels

Larkspur sends notifications in the web app, by email, and as push notifications in the mobile app. Each user chooses which events notify them from Profile > Notifications.

## Email digests

Instead of one email per event, users can switch to a daily digest that is sent at 08:00 in their local time zone. Mentions and task assignments are always sent immediately, even when the digest is on.

## Quiet hours

Users can set quiet hours, during which push notifications are held and delivered when quiet hours end.
