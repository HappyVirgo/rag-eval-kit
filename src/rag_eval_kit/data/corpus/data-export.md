# Exporting Data

> Synthetic documentation for Larkspur, a fictional project-management SaaS. Not a real product.

## Project exports

Any member can export a single project they have access to as CSV or JSON from the project menu. Exports include tasks, comments, and custom fields, but not attachments.

## Full workspace export

Only the workspace owner can start a full workspace export. The export runs in the background and the owner receives an email with a download link when it is ready. The download link is valid for 7 days. Full exports include attachments and are delivered as a ZIP archive.
