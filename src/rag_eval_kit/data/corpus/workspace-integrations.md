# Integrations

> Synthetic documentation for Larkspur, a fictional project-management SaaS. Not a real product.

## Available integrations

Larkspur integrates with Slack, GitHub, GitLab, and Google Drive. The Slack integration posts task updates to a channel and lets people create tasks with the /larkspur command. The GitHub and GitLab integrations link pull requests and merge requests to tasks and close tasks automatically when a linked change is merged.

## Plan requirements

Integrations require the Team plan or higher. Only Admins and Owners can install or remove integrations. Workspaces on the Free plan can still use webhooks and the API to build their own integrations.
